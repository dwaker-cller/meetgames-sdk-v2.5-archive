MeetGames SDK 工具 Demo V2.4

打开方式：
1. 双击“打开Demo.html”；也可以双击“打开Demo.bat”或 index.html。
2. 建议使用 Microsoft Edge 或 Google Chrome 浏览器查看。

使用流程：
1. 在“配置中心”选择游戏，维护支付、登录、协议与隐私、合规、客服工具、归因数据和广告变现参数。
2. 参数未填写完整时也可以保存草稿；已填写内容会保留，但只有完整配置的能力或平台可以在生成 SDK 时使用。
3. 进入“生成及运营中心”，点击“生成SDK”。
4. 在右侧抽屉选择发行渠道、填写包名，并选择本次需要包含的 SDK 能力。
5. 未配置的能力会显示“前往配置”；打开的配置弹窗与配置中心保持一致，并支持保存。
6. 完成发行策略、SDK 和运行开关设置后，点击底部“生成SDK”。
7. 生成后可在列表中下载渠道组合包，或进入运营配置继续调整已包含能力的策略与开关。

平台规则：
- 配置中心的归因数据和广告变现平台卡片允许单选、多选或全部取消；取消展示不会清空已填写参数。
- 生成 SDK 时，Firebase 可以与 AppsFlyer 或 Adjust 共存，AppsFlyer 与 Adjust 二选一。
- 生成 SDK 时，Google AdMob 与 AppLovin MAX 二选一。
- 配置中心维护的是游戏级可复用参数；生成 SDK 抽屉决定当前渠道组合包实际包含的平台，两层选择互不替代。

保存与风险规则：
- 没有发行渠道组合包时，关闭已修改的配置会提示“保存修改 / 不保存 / 取消”。
- 已有发行渠道组合包时，保存或关闭已修改的配置会进入线上 SDK 参数风险确认。
- 风险确认提供“返回检查 / 不保存 / 确认风险并保存”：不保存会撤销本次修改并关闭配置弹窗。
- 输入格式不正确时，字段下方会显示红色错误提示；未完成配置可以保存，但不能作为可用能力打入 SDK。

其他说明：
- 同一游戏的每个发行渠道最多存在一个 SDK 组合包；已有组合包的渠道不可重复生成。
- 支付能力只使用当前发行渠道对应的支付配置，其他渠道支付参数不会生效。
- 登录参数按通用、iOS、Android 分区，并根据发行渠道检查对应参数。
- Guest 为默认必选登录方式；Email、Apple 等无需参数的平台仍可作为登录方式使用。
- 登录配置中的“批量导入”目前仅提供按钮 UI，暂不解析 CSV 文件。
- Firebase 文件上传会记录文件名与浏览器端 SHA-256 元信息；本 Demo 不保存文件二进制。
- 页面数据保存在当前浏览器；更换浏览器或清理浏览器数据后会恢复默认状态。
- Demo 下载的 SDK 文件为模拟交付内容，不含生产二进制或真实密钥。
