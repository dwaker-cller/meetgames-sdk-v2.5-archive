MeetGames SDK 工具 Demo V2.2

打开方式：
1. 双击“打开Demo.html”；也可以双击“打开Demo.bat”或 index.html。
2. 建议使用 Microsoft Edge 或 Google Chrome 浏览器查看。

使用流程：
1. 在“配置中心”右上角选择游戏，填写并保存所需 SDK 能力参数。
2. 进入左侧“生成及运营中心”，在右上角确认游戏后点击“＋”。
3. 在“SDK生成”页面选择发行渠道、填写包名，并勾选本次需要生成的 SDK 能力。
4. 待配置能力会置灰；可返回配置中心补齐，也可跳过该能力继续生成。
5. 点击“生成SDK”并确认后，系统返回中心首页并新增一条 SDK 版本记录。
6. 在版本记录操作列可查看详情、下载或进行运营配置。

规则说明：
- 同一游戏、发行渠道和包名可重复生成，新记录自动递增版本并保留历史版本。
- 历史版本保存生成时的配置快照，不受配置中心后续修改影响。
- 运营配置只能管理已包含在当前版本中的 SDK 能力；如需增减能力，请生成新版本。
- 登录参数按通用、iOS、Android 分区，并根据发行渠道检查通用参数与对应端参数。
- 配置中心右下角“保存”用于统一保存当前游戏的 SDK 配置。
- 广告变现平台只有在对应参数填写完整后才会计入已配置能力。
- App Store 使用通用+iOS 参数；小米商店、Google Play、ONE Store 使用通用+Android 参数。
- 登录配置中的“批量导入”目前仅提供按钮 UI，暂不解析 CSV 文件。
- 页面数据保存在当前浏览器本地；更换浏览器或清理浏览器数据后会恢复默认状态。
- Demo 下载的 SDK 文件为模拟交付内容，不含生产二进制或真实密钥。
