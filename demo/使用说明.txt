MeetGames SDK 工具 Demo V1.5

打开方式：
1. 请先完整解压本压缩包。
2. 双击“打开Demo.html”；也可以双击“打开Demo.bat”或 index.html。
3. 建议使用 Microsoft Edge 或 Google Chrome 浏览器查看。

主要内容：
- 配置中心：按游戏配置发行渠道、登录方式、协议、合规、三方数据与客服。
- SDK 出包：按发行渠道创建 SDK 组合包，填写包名，选择 SDK 能力与包级开关。
- 运营配置：对已生成组合包配置发行国家/地区、区域化登录方式排序、协议选择和 SDK 启用策略。
- 运行监控：查看工具包生成记录与运行指标。

说明：
- 页面在本地离线运行，不需要联网，也不需要安装开发环境。
- 本 Demo 为产品交互演示，页面数据仅用于演示，不会提交到生产环境。
- Demo 中生成的 SDK 文件为模拟交付包，不含生产二进制或真实密钥。
