MeetGames SDK 工具 Demo V1.9

打开方式：
1. 请先完整解压本压缩包。
2. 双击“打开Demo.html”；也可以双击“打开Demo.bat”或 index.html。
3. 建议使用 Microsoft Edge 或 Google Chrome 浏览器查看。

主要内容：
- 配置中心：按游戏管理 SDK 组合包；发行渠道和支付参数必填，登录、协议、合规、三方数据、广告变现与客服配置可按需补充。
- 运营配置：为每个渠道包建立国家/地区发行策略，并按策略维护登录排序、协议分组、合规、客服、三方数据、广告变现及运行开关。
- 配置联动：运营配置中的登录方式、协议分组和年龄门槛承接配置中心当前渠道包的数据。
- SDK 模块：组合包默认包含全部 SDK 能力；运营配置中的六个配置板块默认收起，可点击标题按需展开。
- SDK 组合包：在配置中心首页按发行渠道查看详情、重复下载、删除或进入运营配置。
- 运行监控：查看工具包生成记录与运行指标。

说明：
- 页面在本地离线运行，不需要联网，也不需要安装开发环境。
- 本 Demo 为产品交互演示，页面数据仅用于演示，不会提交到生产环境。
- 运营策略等演示数据保存在当前浏览器本地；更换浏览器或清理浏览器数据后会恢复默认状态。
- Demo 中生成的 SDK 文件为模拟交付包，不含生产二进制或真实密钥。
