MeetGames SDK 工具 Demo V2.0

打开方式：
1. 请先完整解压本压缩包。
2. 双击“打开Demo.html”；也可以双击“打开Demo.bat”或 index.html。
3. 建议使用 Microsoft Edge 或 Google Chrome 浏览器查看。

主要内容：
- 配置中心：按游戏维护支付、登录、协议、合规、三方数据、广告变现与客服配置；“支付方式”固定为第一张卡片。
- 支付方式：展示 iOS / Android 与 App Store、Google Play、Xiaomi GetApps 组合出的四条记录；点击状态可展开参数，右侧可查看说明或删除配置。
- SDK下载：可从游戏名称下方的“SDK下载”标签或页面右下角按钮进入。先选择四个渠道之一，页面再展示包名；完整配置的能力默认加入，待配置能力不可勾选，可点击“去配置”补齐后下载。
- 广告变现：配置中心选择 Google AdMob 或 AppLovin MAX 即可保存；如需在 SDK 包中加入广告变现能力，下载前必须补齐所选平台参数。
- 运营配置：只展示渠道包实际包含的 SDK 能力，并按国家/地区策略维护能力开关和运行配置。
- 运行监控：查看工具包生成记录与运行指标。

说明：
- 页面在本地离线运行，不需要联网，也不需要安装开发环境。
- 本 Demo 为产品交互演示，页面数据仅用于演示，不会提交到生产环境。
- 运营策略等演示数据保存在当前浏览器本地；更换浏览器或清理浏览器数据后会恢复默认状态。
- Demo 中生成的 SDK 文件为模拟交付包，不含生产二进制或真实密钥。
