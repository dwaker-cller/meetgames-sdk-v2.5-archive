MeetGames SDK 工具 Demo
版本：V2.3
更新日期：2026-08-10
入口文件：打开Demo.html

当前版本要点：
- 配置中心只负责按游戏填写并保存支付、登录、协议与隐私、合规、三方数据、广告变现、客服工具参数。
- 左侧“运营配置”更名为“生成及运营中心”，承接 SDK 生成、版本记录、下载与运营配置。
- 游戏名称选择统一放在配置中心、生成及运营中心和 SDK 生成页的右上角。
- 生成及运营中心右上角“＋”进入 SDK 生成，选择发行渠道、填写包名并选择可用 SDK 能力。
- 未完成配置的能力在 SDK 生成页置灰；用户可以跳回配置中心补齐，也可以不选择该能力直接生成。
- 每个游戏的每个发行渠道最多保留一个 SDK 组合包；已有组合包的渠道不可重复新增。
- 版本列表提供“修改”操作，可调整包名和 SDK 能力，但不可修改发行渠道。
- 版本列表展示发行渠道、版本、SDK能力、生成时间与操作；包名仅在版本详情中展示。
- 每个版本支持查看详情、下载和运营配置；运营配置仅管理已打入该版本的 SDK 能力。
- 生成时保存配置快照，后续配置中心参数变化不会影响历史版本的详情与下载内容。
- 登录参数按“通用 / iOS / Android”划分，并按发行渠道校验所需参数。
- 已完成非 Guest 登录配置时，点击“登录”卡片直接进入参数列表；首次配置仍先选择登录方式。
- 密文参数支持通过右侧眼睛图标切换明文；删除配置提供二次确认。
- 登录配置保留“批量导入”按钮 UI，本演示版本暂不解析 CSV 文件。
- 配置中心右下角提供统一“保存”按钮；保存后仅提示成功，不再显示返回 SDK 生成入口。
- 广告平台仅在参数填写完整后视为已选择；只点击平台但未填写参数会按未选择处理。
