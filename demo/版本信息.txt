MeetGames SDK 工具 Demo
版本：V2.5
更新日期：2026-08-14
入口文件：打开Demo.html
运行基线：update=54（20260813-config-generation-54）

当前版本要点：
- 配置中心支持支付、登录、协议与隐私、合规、客服工具、归因数据和广告变现的游戏级参数维护。
- 未完整配置的参数允许保存并在下次继续编辑；生成 SDK 时只能选择已成功配置的能力或平台。
- 归因数据与广告变现的配置中心平台卡支持单选、多选或全部取消，隐藏平台不会清空已填写参数。
- 生成 SDK 使用右侧抽屉，每行两张紧凑能力卡；未配置能力提供“前往配置”入口，快速配置与配置中心使用相同页面和保存逻辑。
- 归因数据在包级选择中允许 Firebase 共存，AppsFlyer 与 Adjust 二选一；广告平台二选一。
- 新建组合包点击“生成SDK”后直接下载模拟 SDK ZIP，并把组合包写入生成及运营中心列表。
- 已有组合包提供“编辑”入口；发行渠道保持不变，可修改包名和 SDK 能力。
- 包名支持独立保存，无需重新生成；独立保存不触发下载、不刷新生成时间，也不修改 SDK 能力、运营配置或上次生成快照。
- SDK 能力变更需点击底部“重新生成”；系统原位更新组合包、刷新生成时间并下载新的模拟 SDK ZIP。
- 已有发行渠道组合包时，参数修改直接进入线上风险确认，不再叠加普通未保存提示。
- 风险确认提供“返回检查 / 不保存 / 确认风险并保存”；配置字段支持即时格式校验，错误信息显示在字段下方。
- 生成时按本包选择裁剪配置快照，不把未选择的平台参数写入渠道组合包。
- 国家/地区策略选择器将已分组国家置底、不显示英文简称，并允许在生成抽屉上方完成策略组编辑。
- 同一游戏的每个发行渠道最多保留一个 SDK 组合包。
- 页面数据保存在浏览器本地；下载内容为 Demo 模拟文件。
