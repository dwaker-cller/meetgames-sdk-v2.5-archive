MeetGames SDK 工具 Demo
版本：V2.1
生成日期：2026-08-06
交付类型：Windows 离线交互演示包
入口文件：打开Demo.html

版本要点：
- 配置中心将“支付”作为第一张 SDK 配置卡，按平台 × 发行渠道维护四组支付参数。
- 游戏名称下方提供“SDK配置 / SDK下载”双标签，配置中心右下角同时提供 SDK 下载快捷入口。
- SDK 下载直接选择四个发行渠道之一；选择渠道后再填写包名，并按渠道联动选择 SDK 能力。
- 已完成配置的 SDK 能力默认选中；待配置能力不可勾选，但可在当前页面直接补充配置。
- 广告变现只需选择平台即可完成基础配置；打入 SDK 包前仍需补齐所选广告平台参数。
- 运营配置与下载产物只承接渠道包实际包含的能力，不再默认补齐全部 SDK。
- 配置页与下载页统一使用“配置中心”页头，游戏选择、修改与添加操作位于页头右侧。
- SDK 下载区采用白色一体化布局；渠道与能力步骤区不再显示独立外框，已选能力使用淡紫底色和完整紫色边框。
- SDK 配置与 SDK 下载统一使用“支付、登录、协议与隐私、合规、三方数据、广告变现、客服工具”七项能力名称。
- SDK 下载页不再显示“清空”按钮，返回操作统一命名为“返回SDK配置”。
- SDK 配置与 SDK 下载的配置弹窗统一标题、说明和操作样式，底部仅在右侧保留“保存”；下载页补充的参数会同步回 SDK 配置。
- 登录配置标题行提供“批量导入”按钮 UI，用于后续接入 CSV 参数导入能力；本演示版本暂不解析文件。
- 每个发行渠道独立保存包名和 SDK 能力选择，切换渠道后返回仍会恢复该渠道草稿。
- 点击“下载”后先展示游戏名称、发行渠道、包名和 SDK 能力清单，确认后再生成模拟 SDK 包。
- 运营配置的游戏选择与页面标题处于同一行，页面不再显示冗余的顶部路径文字。
