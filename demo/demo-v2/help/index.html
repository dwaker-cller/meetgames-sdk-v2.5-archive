01 · 基础项配置

登录方式接入

先选择需要启用的登录方式，再按列填写该方式对应的平台参数。

1创建平台应用取得 Client ID 与密钥
2填写配置中心选择登录方式并录入参数
3生成并联调 SDK使用测试账号验证回调
配置前先确认应用标识

Android 包名、iOS Bundle ID、回调地址必须与平台后台一致。正式环境和测试环境建议分别创建应用，避免密钥混用。

平台参数填写要点

回调地址

将配置中心展示的 Callback URL 原样添加到平台后台，不要自行增加路径或斜杠。

签名与证书

Google 登录需为每套签名添加 SHA-1；平台应用标识与游戏包名应保持一致。

敏感参数

App Secret、P8 私钥等参数仅用于服务端校验，不应打包进游戏客户端。

02 · 三方数据配置

Firebase / AppsFlyer / Adjust 参数获取

三个平台可以多选。只需填写所选平台的必填参数，并在生成 SDK 前完成校验。

Firebase

产品分析 / 崩溃监控

01
  1. 在 Firebase Console 中选择与当前游戏包对应的 Android 或 iOS 应用。
  2. Android 下载 google-services.json，iOS 下载 GoogleService-Info.plist。
  3. 将原始文件上传到配置中心；不要重命名或手工修改文件内容。
参数位置
Android 配置文件上传 Android 应用的 google-services.json
iOS 配置文件上传 iOS 应用的 GoogleService-Info.plist

AppsFlyer

广告归因 / 深度链接

02
  1. 在 AppsFlyer 后台进入 SDK 集成页面，复制当前应用的 Dev Key。
  2. 复制 Dev Key 时保留原始大小写，且不要包含首尾空格。
  3. 从 App Store Connect 复制 Apple App ID，仅保留数字部分。
参数位置
Dev KeyAppsFlyer 后台 → 设置 → 应用设置 → SDK 验证
Apple App ID填写纯数字 App Store ID，不需要添加 id 前缀

Adjust

广告归因 / 事件回传

03
  1. 从 Adjust 应用详情页复制 App Token，并确认它对应当前游戏应用。
  2. 联调阶段使用 sandbox，提交正式发行包前切换为 production。
  3. 为下方 12 个 SDK 标准事件逐项填写 Adjust 后台对应的 eventID。

03 · 合规配置

GDPR、年龄与未成年人合规

系统可提供产品能力，但发行方仍需根据目标国家与地区完成法律评估和文案确认。

合规配置不是一次性开关

请为不同发行区域维护生效范围、文案版本和更新时间；法规或产品数据用途变化后应重新评估。

1

GDPR 隐私协议弹窗

GDPR 开关

开启后，在适用国家首次启动时展示隐私同意弹窗与撤回入口。

  • 明确展示隐私政策、数据用途，并允许用户拒绝非必要数据处理。
  • 取得同意前暂停 Firebase、AppsFlyer、Adjust 等非必要三方初始化。
  • 保留撤回同意与重新授权入口，并记录用户同意的协议版本。
2

年龄阈值

ageThreshold · 0–120

年龄获取与家长控制开启后，低于该年龄的玩家进入 Epic KWS 家长验证。

  • 字段为必填数字，允许范围为 0–120，请按主要发行区域的规则设置。
  • 建议收集年龄或年龄段，避免保存业务不需要的完整出生日期。
  • 年龄结果应与账号绑定，并同步控制三方数据初始化与个性化能力。
3

Epic KWS 家长验证

4 项凭据均必填

通过 Epic Kids Web Services 发起家长验证，并校验完成后的服务端回调。

  • client_id 与 client_secret 用于服务端获取 KWS 访问令牌。
  • verify_secret 用于校验家长验证回调签名，不得下发到客户端。
  • redirect 必须为 HTTPS，并与 Epic KWS 后台登记的回调地址完全一致。

年龄与 Epic KWS 参数

开启「年龄获取与家长控制」后生效；年龄阈值与下列 4 项参数均为必填。

原版字段
